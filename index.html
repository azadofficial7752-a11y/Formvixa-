Help / FAQ

How do I resize a photo or signature?

Select Photo or Signature, tap Choose an image and select your file. Enter your required width and height in pixels, choose a download format, and tap Download Image.

How do I crop an image?

Drag the crop box corners to select the area you want to keep. Tap Apply Crop to set the output dimensions to the selected area. You can then enter different dimensions if required. Your result appears in Output Preview.

How do I change brightness and sharpness?

Move the Brightness or Sharpness slider in Resize & Enhance. Changes appear automatically in Output Preview. Contrast and Saturation can be adjusted in the same way. The crop editor continues to show the original image.

Which download formats are supported?

FORMVIXA offers JPEG, PNG and WebP export. Format availability depends on your browser. If your browser returns a different supported format, the download message indicates the actual format.

Why does my enlarged image look blurry?

Enlarging an image does not restore detail missing from the original. Start with a clear image and avoid excessive enlargement. Sharpness can enhance edges, but it cannot recover missing original details.

Does FORMVIXA support an exact file size in KB?

This version does not include an exact target-KB feature. You can change the output dimensions and adjust export quality for JPEG or WebP to influence file size. Check the downloaded file size before uploading it to an application form.

How do I keep my image from stretching?

Keep Keep aspect ratio enabled. Turn it off only when you need to set width and height independently.

How do I undo my changes?

Tap Reset Adjustments to restore the adjustment sliders. Tap Reset All to reset the crop and adjustments. Tap Full Image to select the full original image.
